# Operations
1. Install and run read-only market discovery.
2. Confirm volume-ranked full-universe scanning.
3. Run sandbox/testnet API credentials where the venue supports it.
4. Verify post-only entry, partial fills, cancel/expire and margin release.
5. Verify stop/TP protective orders are accepted and visible at the exchange.
6. Restart the process and reconcile local state against exchange open orders/positions before resuming.
7. Run OOS/walk-forward on independent data including realistic fees/slippage.
8. Only then consider limited live capital.
