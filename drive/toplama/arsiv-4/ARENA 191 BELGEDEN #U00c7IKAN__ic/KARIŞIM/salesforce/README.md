# Salesforce OmniStudio için salt-okunur taslak

Bu klasör Salesforce **org'una kurulmuş veya orada derlenmiş değildir**. `AcarPaperStatus` GET-only Named Credential çağrısı ve `HttpCalloutMock` testleri kaynak olarak hazırlanmıştır. Salesforce/OmniStudio hesabına, ağ bağlantısına veya credential'a erişilmediğinden Apex testleri bu ortamda çalıştırılmadı. Salesforce sürümü, lisans/OmniStudio runtime ve org politikaları doğrulanmalıdır.

1. Yalnızca kullanıcının denetlediği altyapıda yeni birleşik simülatör DB ve `status_gateway.py` çalıştırılabilir. Gateway varsayılan olarak yalnız `127.0.0.1` dinler; Salesforce doğrudan localhost'a erişemez. Üretim ortamında, TLS, ağ kısıtları, uygun auth ve audit içeren bir reverse proxy/güvenli ulaşım katmanı ayrıca gereklidir. Önizleme sunucusunu veya kimlik doğrulamasız mevcut `app.py` panelini internete açmayın.
2. Salesforce'ta modern **Named Credential + External Credential** kullanarak `ACAR_PAPER_STATUS` adını, güvenli gateway taban adresini ve uygun principal erişimlerini tanımlayın. Bearer token yerel gateway'in `ACAR_GATEWAY_TOKEN` değerine uygun güvenli header ile gönderilmelidir; gizli değerleri kaynak koduna veya ZIP'e koymayın. Organizasyonunuzun kimlik doğrulama modelini ayrıca doğrulayın. Salesforce dokümanı: [2](https://developer.salesforce.com/docs/platform/named-credentials/guide/get-started.html).
3. Sandbox/developer org'da önce `sf project deploy validate` ve ardından org politikanıza uygun deployment/testi uygulayın. Apex testleri `HttpCalloutMock` kullanır; gerçek gateway bağlantısını doğrulamaz.
4. OmniStudio Integration Procedure HTTP Action ile Named Credential ve `/v1/status` GET yolunu kullanın; dönüş JSON alanlarını FlexCard/OmniScript'e eşleyin. İsteğe bağlı Apex sınıfı JSON metni döndürür; doğrudan Remote Action/FlexCard konfigürasyonunun org'un managed/standard runtime şartlarına göre uyarlanması gerekebilir. Integration Procedure/FlexCard metadata bu klasörde deploy edilmiş hazır yapı değildir.
5. Dönüş `mode: PAPER_SIMULATION` ve `integrationState: DEPLOYMENT_NOT_VERIFIED` içerir. Kimlik doğrulama hatası, bağlantı hatası veya şema uyuşmazlığı işlem izni vermez. Yalnız durum gösterimi; uzaktan emir veya risk ayarı yazma yoktur.

Gateway tazeliği istek anındaki duvar saatiyle hesaplar; açık pozisyonda bayat mark/funding veya belirsiz geçmiş `equityReliable=false` yapar. `workerStatus: NOT_OBSERVED`, worker canlılığının doğrulanmadığını gösterir.
