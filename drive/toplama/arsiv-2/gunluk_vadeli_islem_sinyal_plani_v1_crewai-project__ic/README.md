# gunluk_vadeli_islem_sinyal_plani Flow

This project defines a declarative CrewAI Flow in `src/gunluk_vadeli_islem_sinyal_plani/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/gunluk_vadeli_islem_sinyal_plani/flow.yaml` to change the flow. Add reusable crews under `src/gunluk_vadeli_islem_sinyal_plani/crews/`, custom Python tools under `src/gunluk_vadeli_islem_sinyal_plani/tools/`, and shared knowledge files under `src/gunluk_vadeli_islem_sinyal_plani/knowledge/`.
