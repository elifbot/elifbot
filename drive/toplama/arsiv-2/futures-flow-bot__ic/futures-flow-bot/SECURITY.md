# Guvenlik

- API anahtarlari repoya, loglara, ekran goruntulerine ve sohbetlere ASLA konmaz. Sadece `.env` / sunucu ortam degiskeni.
- Anahtarlarda **cekim (withdraw) izni kapali**, **IP beyaz listesi acik** olmali.
- Bot icin **ayri alt hesap** kullanin; sadece botun bütçesi orada olsun.
- Bir anahtar sizdiysa: borsada hemen silin, yenisini olusturun, `git log` icinde gectiyse repoyu temiz kabul etmeyin.
- Zafiyet/sorun bildirimi: repo sahibine ozel mesaj veya GitHub "Security" sekmesi.
