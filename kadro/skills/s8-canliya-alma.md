# S8 · Canlıya alma kapısı (go-live)

Hepsi sağlanmadan canlı para yok:
- [ ] 30 gün kesintisiz paper koşu (kopma < 0.1/gün)
- [ ] Gerçek tick arşiviyle walk-forward: test PF > 1.1
- [ ] En kötü tek işlem ≥ −10.6 $ (1.000 işlemde)
- [ ] Kullanılan teminat hiçbir anda > kasa
- [ ] Tasfiye sayısı = 0
- [ ] Uzlaştırma (ledger ↔ borsa) 100 koşuda fark = 0
- [ ] Anahtar: çekim kapalı, IP kısıtlı
- [ ] Kill switch testi: veri kesilince 10 sn içinde işlem duruyor
- [ ] İlk canlı hafta: minimum miktar (10 $ teminat) ile pilot

Kabul: maddelerin her biri kanıt dosyasıyla işaretlenir.
